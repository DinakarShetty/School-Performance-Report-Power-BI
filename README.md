# School-Performance-Report-Power-BI
This Power BI dashboard analyzes school performance using Excel-based data and DAX measures.

## 📊 Dashboards Included
1. Student Performance Report
2. Faculty Performance Report
3. Management Summary Report

## 🧠 Technologies Used
- Power BI (DAX, Power Query)
- Microsoft Excel (Data source)
- GitHub for project documentation

## ⚙️ DAX Highlights
- Avg Marks, Pass Rate %, Faculty Feedback, Attendance Analysis

## 📈 Insights
- Identified top-performing subjects and teachers
- Highlighted student performance trends across years
- Provided actionable management insights for resource planning
